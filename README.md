# แผนประชาสัมพันธ์ MDes 2569–70

เว็บแผนโพสต์ Facebook ของหลักสูตรการออกแบบมหาบัณฑิต (MDes) Thammasat Design School

- `data.json` ข้อมูลโพสต์ทั้งหมด (แก้ผ่านปุ่ม "สำหรับผู้ดูแล" ในเว็บ หรือแก้ไฟล์นี้ตรง ๆ)
- `index.html`, `style.css`, `app.js` ตัวเว็บ
- สีและฟอนต์ตาม TDS Brand Design Guideline (MDES colour code)
